# Sons do Jogo

Esta pasta contém os arquivos de áudio para efeitos sonoros do jogo.

## Arquivo necessário

Para o som de coleta de moeda funcionar, adicione um arquivo de áudio com um dos seguintes nomes:

- `coin_collect.ogg` (recomendado)
- `coin_collect.mp3`
- `coin_collect.wav`

O código tentará carregar nessa ordem até encontrar um arquivo disponível.

## Formato recomendado

- **Formato**: OGG Vorbis (.ogg) - melhor compressão e qualidade
- **Duração**: 0.2 - 0.5 segundos (som curto e agradável)
- **Volume**: Normalizado (evitar clipping)

## Onde encontrar sons gratuitos

- [Freesound.org](https://freesound.org) - Busque por "coin collect" ou "coin pickup"
- [OpenGameArt.org](https://opengameart.org) - Sons de jogos gratuitos
- [Zapsplat](https://www.zapsplat.com) - Biblioteca de sons gratuitos (requer cadastro)
